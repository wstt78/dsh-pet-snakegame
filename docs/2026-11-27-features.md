# 2026-11-27 功能补齐：右键菜单 / 设置页 / 立绘导入 / 便携打包

## 现象与目标

基础模板只能靠托盘和热键启动，参数写死在 `game-core.mjs`，换立绘要改代码，交付物是源码目录。
目标：补上简报 §13 剩余的四件事，并让非技术用户双击就能跑。

## 链路

```
托盘/热键/右键 ──> src/main.js
                     ├─ 读 src/config.js（config.json，坏文件回落默认）
                     ├─ BrowserWindow(透明, 置顶, 穿透) ──> index.html → app.mjs → game-core.mjs / draw.mjs
                     ├─ spawn bin/input-helper.exe --stdin ──> IPC pet:input
                     ├─ 设置窗口 settings.html → settings.mjs ──> IPC settings:get/save/import/reset
                     └─ 命中区：app.mjs 每帧算 hitZone() ──> IPC pet:hit-test ──> setIgnoreMouseEvents(!inside)
```

## 机制（关键决定）

1. **右键入口**：整窗穿透时收不到鼠标事件，所以只有光标落在 `hitZone()`（立绘矩形，约 230×250）且状态为 sleep 时才临时 `setIgnoreMouseEvents(false)`；移开立刻恢复。探针关闭时拿不到光标，强制保持穿透（否则会永久卡住）。
2. **设置立即生效**：`config.save()` 校验→写盘→广播 `pet:config`；渲染层 `game.applyConfig()` 直接改同一份 cfg（`InputTracker` 持有同一个对象引用），立绘变化则换 `<img>`。输入探针开关切换会实际拉起/停掉子进程。
3. **立绘导入**：主进程弹系统文件框→复制到 `assets/pet-user-<ts>.<ext>`→改配置。GIF/WebP 不自己解码，靠 `<img>` 原生播放、canvas 每帧 `drawImage` 取当前帧。
4. **打包不联网**：直接复制已安装的 `node_modules/electron/dist`，把 `src/assets/bin/package.json` 放进 `resources/app`（Electron 在没有 app.asar 时优先加载该目录），重命名 exe。避免 electron-builder 下载。

## 爆炸半径

- 只动 `whale-snake-pet` 工程；未碰 surfcore 工作区（那里有别人未提交的改动）。
- 新增磁盘：`dist/WhaleSnakePet` 约 358 MB（Electron 运行时）。
- 进程：一个 Electron 主进程 + 一个输入探针；设置窗按需创建。
- 用户数据：只在程序目录写 `config.json`、`logs/main.log`、`assets/pet-user-*`；删文件夹即卸载。

## 取舍

- 选「命中区临时取消穿透」而不是「整窗可点」：后者会把桌面变成死区。代价：宠物区域左键也会被吃掉，可右键出菜单。
- 选「自写 config.js」而不是 electron-store：零依赖、可被 node --test 直接测；代价是校验逻辑要自己维护。
- 选「便携文件夹」而不是安装包：不需要签名/管理员权限、可整包删除；代价是体积大、SmartScreen 会提示未知发布者。

## 生效与重启

- 改代码/打包后要重启 exe；设置页保存立即生效，无需重启。
- 探针开关切换会重启子进程，不需要重启 Electron。

## 回滚

- 关掉右键：设置里取消「光标停在宠物上时可右键」，或 `config.json` 写 `rightClickMenu:false`。
- 关掉新功能整体：`git`（若纳入版本管理）回退 `src/main.js`、`src/renderer/app.mjs`，并删 `config.js`/设置页；旧版无 config 依赖。
- 打包物：直接删 `dist/`。
