# 鲸鱼娘桌宠贪吃蛇

一个住在 Windows 桌面上的透明置顶小游戏。启用插件后，桌宠随 DSH 启动；停用插件时桌宠退出。

## 它做什么

- 空闲 10 秒后，右下角的鲸鱼娘变成一条鲸鱼尾巴的贪吃蛇，在你桌面上游动。
- 移动鼠标进入「追光标」状态：蛇头追着光标走，吃掉场上的 token 球 / 白米饭，身体变长。
- 连续输入（键盘/鼠标点击）达到工作信号时，它安静缩回右下角，15 秒内不再自动出现。
- 撞到自己或红色障碍物会「撞晕」，回到鲸鱼娘形态。

## 使用前提

这是 Windows x64 的 Electron 桌面程序，插件只负责启动/停止它：

1. 插件会在首次启用时从 GitHub Release 下载 `WhaleSnakePet-win-x64.zip`，解压到
   `%LOCALAPPDATA%\dsh-pet-snakegame\app\`（约 360 MB，需要网络）。
2. 也可以手动下载同一个 zip，解压后把 `WhaleSnakePet.exe` 的完整路径填到插件配置的
   `exePath`（插件行的配置编辑器），或设置环境变量 `DSH_PET_EXE`。

## 配置

- `autoStart`（默认 `true`）：插件启用时自动启动桌宠。
- `exePath`（默认空）：自定义 `WhaleSnakePet.exe` 路径；为空时用缓存目录里的版本。

## 已知限制

- 只支持 Windows x64；没有做 macOS / Linux 版本。
- 桌宠窗口是透明置顶、鼠标穿透的覆盖层，不拦截桌面点击。
- 首次下载 360 MB；GitHub 不可达时需要手动放置 exe 并填 `exePath`。
- 桌宠与 DSH 生命周期绑定：停用插件 / 退出 DSH 时会被结束。
